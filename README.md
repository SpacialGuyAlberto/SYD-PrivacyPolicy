## 🌐 Deploying with GitHub Pages

This repository is ready for immediate deployment on **GitHub Pages**:

1. Push this repository to GitHub (e.g. `https://github.com/<your-username>/SYD-PrivacyPolicy`).
2. In your GitHub repository, navigate to **Settings** > **Pages** (under the "Code and automation" section).
3. Under **Build and deployment**:
   - **Source**: Select `Deploy from a branch`
   - **Branch**: Select `main` and folder `/ (root)`
   - Click **Save**.
4. In 1–2 minutes, your policy will be live at:
   - **Interactive Hub**: `https://<your-username>.github.io/SYD-PrivacyPolicy/`
   - **German URL**: `https://<your-username>.github.io/SYD-PrivacyPolicy/privacy-de.html` (or `.../?lang=de`)
   - **English URL**: `https://<your-username>.github.io/SYD-PrivacyPolicy/privacy-en.html` (or `.../?lang=en`)
   - **Spanish URL**: `https://<your-username>.github.io/SYD-PrivacyPolicy/privacy-es.html` (or `.../?lang=es`)

> **Note for App Store & Google Play Console**:  
> You can provide the direct language URLs (`privacy-en.html`, `privacy-de.html`, `privacy-es.html`) or the main hub (`index.html`) as your public Privacy Policy URL.
